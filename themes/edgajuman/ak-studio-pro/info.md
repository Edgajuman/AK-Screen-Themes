# AK Studio Pro

Para AK Screen 2.2.0 o posterior. Incluye todos los tipos de personalizacion nativa: 47 colores, 11 metricas, disposicion de paneles, hoja CSS, colores de clips y recursos, iconos SVG, fuente local, fondo WebP y splash GIF. Los iconos restantes conservan el dibujo nativo del editor.

Instala desde Temas → Catalogo → Actualizar → AK Studio Pro → Instalar y aplicar. Cada PC guarda el paquete en su propia carpeta de temas. Ajusta la opacidad del fondo y duracion de carga desde Configuracion → Temas y apariencia; estas preferencias son del usuario.

Para crear una variante, cambia id, nombre y autor; edita theme.json/editor.css, aporta una vista previa y envia un pull request. Los hashes se generan automaticamente. Las fuentes solo se usan dentro del editor.

La vista previa es una ilustracion original del diseño, no una captura de la aplicacion. Los fondos, dibujos, CSS y layout son obra original de AK Screen bajo MIT OR Apache-2.0. Fuente M PLUS Rounded 1c: M+ FONTS PROJECT, SIL OFL 1.1, conservada sin cambios de Sakura Pulse con su licencia completa.

El CSS usa selectores nativos y valores admitidos. No ejecuta scripts, no inserta herramientas ni modifica los videos exportados.
