# Studio Gallery

AK Screen 2.4.0.

Galería nativa de tres columnas con animación al pasar el mouse; layout guardado con Effects activo, monitor central, propiedades a la derecha y timeline inferior. Todos los tokens de color, métricas, iconos y fuente local siguen el formato real del editor.

El CSS es nativo, acotado; no ejecuta scripts ni interpreta HTML. Fondo y carga animada incluidos. La opacidad del fondo se ajusta en Configuración → Apariencia. La imagen de catálogo es ilustrativa; las capturas reales se publican en el repositorio de descargas.

Modifica editor.css y theme.json, comprueba el catálogo y envía un pull request. Licencias en LICENSE.txt y assets/fonts.
