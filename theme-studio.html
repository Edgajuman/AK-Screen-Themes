PAQUETE REVISABLE

Exportar y publicar

Descarga una carpeta ZIP con la estructura lista para añadir a tu fork del catálogo.

ESTRUCTURA DEL PAQUETECalculando…
themes/
└── tu-usuario/
    └── ak-studio-pro/
        ├── theme.json
        ├── preview.png
        ├── info.md
        ├── editor.css
        └── assets/
!

Antes del pull request, añade créditos y licencias reales en info.md y valida con python scripts/catalog.py --check. El catálogo solo publica temas después de que se acepte el PR.

Después descomprime el ZIP en themes/<tu-usuario>/<id>/, revisa los archivos y abre un pull request en AK-Screen-Themes.
